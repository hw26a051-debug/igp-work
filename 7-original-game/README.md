# ゲーム制作雛形

自分のゲーム作品を作るための雛形です。

初期状態では、タイトル画面 → プレイ画面 → リザルト画面 → タイトル画面、と進む最小限の仕組みだけが入っています。
この雛形を参考に、自分の作品を作っていってください。
画面構成などは必要に応じて自由に変更して構いません。

## 起動方法

`index.html` を**ダブルクリックで開いても動作しません**。
VS Code の Live Server 拡張機能を使って開いてください。

1. VS Code の左側のエクスプローラーで `index.html` を右クリックし、「Open with Live Server」を選びます。
2. ブラウザでタイトル画面が開きます。以降、コードを書き換えて保存すると、ブラウザの表示も自動で更新されます。

## 操作方法（仮の内容）

| 画面 | 操作 |
|---|---|
| タイトル | スペースキーでプレイ開始 |
| プレイ | 矢印キーで自機を移動、X キーでリザルトへ |
| リザルト | スペースキーでタイトルに戻る |

## ファイル構成

```
index.html           … ページ本体。p5.js と、自分の JavaScript コードを読み込む
js/
├── config.js        … 全体で使う定数（キャンバスの大きさ等）
├── image.js         … 画像の読み込み（新しい画像はここに追加）
├── sound.js         … 効果音の読み込み（新しい効果音はここに追加）
├── input.js         … キー入力
├── main.js          … 全体の流れ（preload / setup / draw、画面の切り替え）
└── screens/
    ├── title.js     … タイトル画面
    ├── playing.js   … プレイ画面
    └── result.js    … リザルト画面
assets/images/       … 画像アセットの保存場所
assets/sounds/       … 効果音アセットの保存場所
```

## index.html の中身

`index.html` は、ブラウザが最初に開くページです。ゲームに必要なファイルを読み込むのが主な役割です。

- `<title>` … ブラウザのタブに表示される名前です。**自分の作品の名前に変えて**ください。
- p5.js と p5.sound の `<script>` … インターネット上（CDN）から読み込みます。インターネットに接続していないと動きません。
- `<style>` … ページの背景を暗くして、ゲームの画面（キャンバス）を中央に表示します。
- `js/` の `<script>` … 自分で書いた JavaScript ファイルを読み込みます。

### JavaScript ファイルを追加したい場合

1. `js/` の中に、新しいファイル（例: `js/enemy.js`）を作ります。
2. `index.html` で、`js/main.js` の 1 つ上に `<script src="js/enemy.js"></script>` を追加します。

`<script>` を追加し忘れると、そのファイルは読み込まれないので注意しましょう。

### 読み込む順番と、名前の重なり

- JavaScript ファイルは、上から順番に読み込まれます。他のファイルの関数を呼ぶだけなら、順番は関係ありません。ただし、関数の外で他のファイルの定数・変数・関数を使っている場合は、使われる側のファイルを先に読み込む必要があります。`config.js` が一番上にあるのは、全体で使う定数が入っているからです。`main.js` は全体の流れをまとめるファイルなので、一番最後にしています。
- ファイルが別でも、関数の外側に同じ名前の定数・変数を作ってはいけません。`const` や `let` が重なると、エラーになります。また、同じ名前の関数を作ってしまった場合は、エラーにならずに、後から読み込まれた方で上書きされます。

## プログラムの流れ

次の 3 つの関数は、`js/main.js` にあり、どれも p5.js から自動的に呼び出されます。

1. `preload()` … 画像と効果音を読み込む（最初に 1 回だけ）
2. `setup()` … キャンバスを作り、最初の状態にする（最初に 1 回だけ）
3. `draw()` … 今の画面（`gameData.gameState`）に応じて、更新と描画をする（毎フレーム繰り返す）

画面を切り替えたいときは、同じく `js/main.js` にある `goToTitle()` / `startGame()` / `goToResult()` を呼びます。

## 入力の取得方法

キーの入力は、`js/input.js` にある 2 つの関数で調べます。

※難しければ、`js/input.js` の中身を理解しなくても今は問題ありません。下記関数の使い方だけ理解してください。

| 関数 | `true` になるとき | 使いどころ |
|---|---|---|
| `wasKeyPressed(key)` | キーが**押された瞬間**だけ（1 回のみ） | 画面の切り替え、ジャンプや発射のように、1 回だけ反応させたいとき |
| `isKeyDown(key)` | キーが**押されている間**ずっと | キャラクターの移動のように、押しっぱなしを使いたいとき |

```js
if (isKeyDown('ArrowLeft')) {
  player.x -= PLAYER_SPEED; // 押している間、毎フレーム動く
}
if (wasKeyPressed(' ')) {
  startGame(); // 押した瞬間に 1 回だけ呼ばれる
}
```

### キーの指定のしかた

どちらの関数も、キーを**文字列**で指定します。

| キー | 指定 |
|---|---|
| 英字・数字 | `'x'`、`'1'`（大文字・小文字は区別しません。`'X'` と書いても同じです） |
| スペース | `' '`（半角スペース 1 つ） |
| 矢印 | `'ArrowLeft'`、`'ArrowRight'`、`'ArrowUp'`、`'ArrowDown'` |
| エンター | `'Enter'` |

### 注意すること

- これまでの課題で使った `keyIsDown(LEFT_ARROW)` と違い、`LEFT_ARROW` のような数値（定数）は渡せません。`isKeyDown('ArrowLeft')` のように、文字列で書いてください。
- 日本語入力がオンのままだと、キーが反応しないことがあります。ゲームを遊ぶときは、英数入力に切り替えてください。
